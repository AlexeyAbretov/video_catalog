# Инструкции для ИИ

Закон проекта — `docs/CONSTITUTION.md`. Эта страница говорит, как его применять в коде. Зачем нужен каталог — `README.md`. Запуск, ключи и скан — `docs/setup.md`.

Перед правкой поведения прочитай конституцию. Если правка меняет обещание из статьи, обнови статью в той же правке. Если меняется запуск, ключ или то, что видит человек в инструкции по запуску, обнови `docs/setup.md`. Если меняется смысл приложения, обнови `README.md`.

## Как менять

Обход диска живёт в `scanner.py`. Решение «этот файл уже был» — пара шары и относительного пути в `upsert_file`. Удаление пропавших файлов — в `scan_service._delete_missing` и только после полного обхода шары.

Разбор имени не ходит в сеть: это `filenames.py` и промпт в `providers.py`. Сеть карточки — `enrich.py` и клиенты в `providers.py`. Порог уверенности не размазывай по `enrich.py`: его считает `matching.classify`.

Путь для плеера собирает `paths.py`. Страница только выбирает, какой путь показать: Windows — m3u, macOS и Android — `smb://`.

Новая надпись для человека — по-русски, в компоненте страницы.

## Проверки

Из каталога `vharvest`:

```powershell
python -m unittest discover -s tests
```

После изменения `filenames.py`, `matching.py`, `translit.py`, `paths.py` или `cards.py` тесты обязательны. Не удаляй проверку, чтобы тест стал зелёным.

## Чего не делать без прямой просьбы

- Не отдавать байты фильма через сайт и не монтировать шары на запись.
- Не удалять строки каталога, если обход шары оборвался или шара не смонтирована.
- Не запускать второй скан, пока идёт первый, и не обходить шары при сбросе карточек.
- Не понижать пороги `classify`, чтобы сомнительное имя стало `matched`.
- Не ставить вход на каталог. Токен закрывает только скан и сброс.
- Не переносить Ollama в Compose.
- Не коммитить `.env` и `certs/`. Не писать в лог пароль шары, ключи API, `SCAN_TOKEN` и ключ удостоверяющего центра.
