# Каталог фильмов

Фильмы уже лежат на дисках, которые раздаёт роутер Keenetic. Имена файлов релизные: кодек, озвучка, группа. По ним неудобно вспомнить, что смотреть. Приложение собирает из этих файлов каталог с нормальными карточками и открывает его на любом устройстве в домашней сети.

Сайт показывает название, постер, год, жанры, актёров и рейтинги TMDB и Кинопоиска. Можно отфильтровать по году, жанру и актёру, оставить неполные карточки или те, где год в имени файла не совпал с годом карточки. Номер карточки копируется: его отдают на повторный разбор, если название определилось неверно.

Кино через сайт не идёт. На Windows кнопка «В плеер» скачивает короткий список для VLC или MPC-HC с путём `\\Keenetic-1601\...`. На macOS и Android ссылка `smb://` открывает файл в плеере и папку в Finder или CX Проводнике. Устройство само должно видеть шары.

Обход дисков, разбор имён и запись карточек делает служба `vharvest`. Сайт их только показывает.

Как поднять, какие ключи нужны и как запустить скан — в [docs/setup.md](docs/setup.md).

Законы каталога — в [docs/CONSTITUTION.md](docs/CONSTITUTION.md). Как править код — в [AGENTS.md](AGENTS.md).
